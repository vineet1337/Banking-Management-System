# Banking Management System

A Java-based Banking Management System that demonstrates Object-Oriented Programming, authentication, and custom exception handling.

## Features

- Customer and Bank classes
- Displays customer and bank information
- User authentication before performing banking operations
- Check account balance
- Deposit money
- Withdraw money
- Custom exception handling for invalid credentials
- Custom exception handling for insufficient balance

## Technologies Used

- Java
- Object-Oriented Programming (OOP)
- Exception Handling

## Custom Exceptions

- `InvalidCredentialException`
- `InsufficientBalanceException`

## Project Structure

- `Main.java` — Runs the application and handles user interaction
- `Customer.java` — Handles customer information and authentication
- `BankAccount.java` — Handles account information and banking operations
- `InvalidCredentialException.java` — Handles invalid authentication
- `InsufficientBalanceException.java` — Handles insufficient balance
